=======================================
TYPO3 extension ``theme_kumano_kodo``
=======================================

This extension provides the theme Kumano Kodo, built from the Kumano Kodo
design system.

:Repository:  https://github.com/hahnmg/kumano-kodo
:Issues:      https://github.com/hahnmg/kumano-kodo/issues
:Read online: https://hahnmg.github.io/kumano-kodo/manual/Index.html

Stylesheets, scripts, fonts and generated partials in ``Resources/Public`` and
``Resources/Private`` ship built. They are built from the design system in the
repository with ``npm run build:typo3`` (and ``npm run fonts`` for the fonts);
see its ``README.md``.
