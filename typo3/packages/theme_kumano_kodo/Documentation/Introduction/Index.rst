============
Introduction
============

Kumano Kodo is a theme for a travel journal: calm pages, large photos, one
accent colour. It is one extension, `typo3/theme-kumano-kodo`, that installs
empty; its features are sets a site switches on: the theme and the journal's own
elements. The demo is a package of its own that installs as a site; a starter of
five pages is created from the backend or the command line
(:ref:`installation`).

What it covers is listed on the :ref:`start page <start>`.
