=====================
Kumano Kodo for TYPO3
=====================

:Extension key:
    kumano_kodo

:Package name:

:Version:
    |release|

:Language:

:Author:

A theme for TYPO3 v14: site set, page layouts, 14 content elements in two containers, and templates for search,
login and forms. It renders without fluid_styled_content.
