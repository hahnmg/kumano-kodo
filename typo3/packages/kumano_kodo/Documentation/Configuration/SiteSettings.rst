Site settings
#############

Sites › Setup › Edit settings of the site. Empty fields and colours left at
their default keep the theme's value.

..  important::

    After saving, flush the frontend caches (the lightning icon in the toolbar).
    The settings editor clears neither the page nor the TypoScript cache, so
    pages keep the old values until then.

Appearance
==========

.. confval:: kumanoKodo.theme
    :name: kumanokodo-theme
    :type: string
    :Default: `caramel`

    Theme. Colours, typefaces and spacing of the whole site; the settings below
    override single values.

    One of `caramel`, `forest`, `ocean`, `violet`, `mono`.

.. confval:: kumanoKodo.brand.upright
    :name: kumanokodo-brand-upright
    :type: string
    :Default: (empty)

    Upright name. Set vertically beside the journal title; decorative, hidden
    from screen readers. Empty: none.

.. confval:: kumanoKodo.brand.footerWordmark
    :name: kumanokodo-brand-footerwordmark
    :type: bool
    :Default: `false`

    Website title large in the footer. Decorative, hidden from screen readers.

.. confval:: kumanoKodo.brand.logo
    :name: kumanokodo-brand-logo
    :type: string
    :Default: `title`

    Logo. Shown while the home page has no logo of its own (page properties, tab
    Appearance).

    One of `title`, `kumano`.

.. confval:: kumanoKodo.scheme
    :name: kumanokodo-scheme
    :type: string
    :Default: `light`

    Colour mode on load.

    One of `light`, `dark`.

.. confval:: kumanoKodo.schemeToggle
    :name: kumanokodo-schemetoggle
    :type: bool
    :Default: `true`

    Show the dark mode toggle.
