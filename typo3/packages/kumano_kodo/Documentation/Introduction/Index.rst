============
Introduction
============

Kumano Kodo is a theme for a travel journal: calm pages, large photos, one
accent colour. It is one extension, `kumano-kodo/theme`, that installs empty;
its features are sets a site switches on: the theme, news, the journal's own
elements and the demo. The demo and a starter of five pages are created as sites
of their own, from the backend or the command line (:ref:`installation`).

What it covers is listed on the :ref:`start page <start>`.
