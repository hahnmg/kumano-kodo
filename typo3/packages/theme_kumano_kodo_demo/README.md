# Kumano Kodo demo

The trail journal for the theme `typo3/theme-kumano-kodo`, in English, German
and Japanese with photos. TYPO3 imports it once when the package is set up, as
the site `kumano-kodo` on `/`, like any distribution in the installer.

`Initialisation/` is generated: `npm run export:demo` in the repository builds
it from `typo3/Build/Demo/content.json`. Photos: CC BY 4.0, see
`img/LICENSE.md` in the repository.
