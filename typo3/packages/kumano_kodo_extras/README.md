# Kumano Kodo extras

What the theme `typo3/theme-kumano-kodo` offers for third-party extensions. It
stays outside the TYPO3 core, so the theme itself needs none of them.

| Set                             | Needs              | Does                                                                 |
| ------------------------------- | ------------------ | -------------------------------------------------------------------- |
| `kumano-kodo/theme-extras-news` | `georgringer/news` | News as teaser cards with pages, and a detail page with its gallery |

Add the set to a site that uses the theme. Readable news URLs need the route
enhancers of the news manual's quick start.
