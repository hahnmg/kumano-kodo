# Fluid components

Every part in this Storybook is also a Fluid component in TYPO3. Templates of other extensions use them, so a news or
blog list looks like the rest of the site without CSS of its own. The reference is generated from the component
templates in `typo3/packages/theme_kumano_kodo/Resources/Private/Components`; the manual explains the rules.

```html
<html
    xmlns:f="http://typo3.org/ns/TYPO3/CMS/Fluid/ViewHelpers"
    xmlns:kk="http://typo3.org/ns/TYPO3/CMS/ThemeKumanoKodo/Components"
    data-namespace-typo3-fluid="true"
>
    <kk:teaserCard title="{item.title}" href="{f:uri.typolink(parameter: item.link)}" image="{item.image -> f:first()}" />
</html>
```
