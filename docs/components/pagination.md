# Pagination

Figma: Pagination (19:129), page button (19:128). Markup: `stories/molecules/pagination.markup.ts`.

Page links with collapsed gaps; the current page in the accent colour.

| Prop | Values |
|---|---|
| `current`, `total` | numbers |
| `href` | function from page number to URL |
| `label` | accessible name, default "Pages" |

Tokens: `--color-muted`, `--color-ink`, `--color-accent`, `--space-8`.
