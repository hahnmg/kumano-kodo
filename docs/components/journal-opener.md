# Journal Opener

Figma: Journal Opener (61:218). Markup: `stories/organisms/journal-opener.markup.ts`.

The opening of the home page without an image: a small kicker, a large title, a short lede with dates, and the name set
vertically (熊野古道) as the one graphic element. The vertical text is decorative and hidden from screen readers.

| Prop | Values |
|---|---|
| `kicker`, `title`, `lede`, `meta` | text |
| `vertical` | optional vertical text |
