# Icon

Figma: `Icon/*` components on the page "Components". Markup: `stories/atoms/icon.markup.ts`.

24px stroke icons in the accent colour. Decorative unless `label` is given.

| Prop | Values |
|---|---|
| `name` | clock, phone, mail, map-pin, home, file, search, chevron-down, alert, arrow-right, sun, download |
| `size` | px, default 24 |
| `label` | optional accessible name |

Tokens: `--color-accent`.
