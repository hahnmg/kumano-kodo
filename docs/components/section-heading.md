# Section Heading

Figma: Section Heading (6:33). Markup: `stories/molecules/section-heading.markup.ts`.

Optional eyebrow above an H2; the single heading pattern for every section.

| Prop | Values |
|---|---|
| `title` | text |
| `eyebrow` | optional; omit to hide |
| `variant` | `default`, `with-aside` (text on the right), `with-controls` (carousel arrows) |
| `aside` | text for `with-aside` |
| `level` | 1 or 2, default 2 |

Tokens: `--color-accent`, `--color-ink`, `--color-muted`, `--space-20`, `.type-h2`, `.type-label`.
